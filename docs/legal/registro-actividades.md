# Registro de actividades de tratamiento — PalaClass como encargado (art. 30.2 RGPD)

*Texto base. Revisar con un asesor.*

| Campo | Contenido |
|---|---|
| Encargado | [Nombre / razón social de PalaClass], [contacto] |
| Responsables | Cada club cliente (ver lista de contratos firmados) |
| Categorías de tratamiento | Gestión de escuelas de pádel: grupos, clases, asistencia, bajas, recuperaciones, fichas, chat y avisos |
| Categorías de datos | Identificativos (nombre, email); académicos/deportivos (nivel, asistencia); comunicaciones (chat); salud (lesiones, si el club los anota) |
| Interesados | Alumnos (incluidos menores), profesores |
| Transferencias internacionales | Cloudflare y GitHub (EE. UU.) con cláusulas contractuales tipo / Data Privacy Framework. Base de datos en la UE |
| Subencargados | Supabase (UE), Cloudflare, Brevo (Francia), GitHub |
| Plazo de supresión | Al terminar el contrato con el club: devolución y borrado en 30 días; copias cifradas en 90 días |
| Medidas de seguridad | HTTPS; acceso por código de un solo uso; seguridad a nivel de fila por club y rol; escrituras solo por funciones con control de permisos; copias semanales cifradas; claves secretas fuera del código |
